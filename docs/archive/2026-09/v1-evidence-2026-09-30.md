## Final bounded repairs

- Recovery separates peer address validation from the local amplification exemption, applies ACK delay according to handshake confirmation, and uses a loss epoch spanning packet-number spaces. Focused regressions cover PTO backoff, old ACKs and ACK-only behavior.
- PTO probes now retain the source packet in recovery and send a new packet number; original and probe bytes-in-flight are accounted independently, and a late ACK for the source packet is covered by an exact regression.
- Codec buffer consumption now advances a cursor and compacts amortized, preventing batched tiny HTTP/2/3 frames from forcing quadratic suffix copies. Policy-denied accepted peers no longer consume the supervisor's fatal accept-error budget.
- HTTP/3 frame decoding now inspects varints in the backing array and copies only the current frame, retaining the same amortized suffix behavior for batched tiny frames.
- Retry uses a bounded token manager and an opaque validated context. Retry CRYPTO replay and recovery after losing the first post-Retry Initial pass with the real Native TLS provider.
- AEAD use is counted separately for Initial, Handshake and Application keys; limit and key-phase failures retain typed errors. Five new boundary tests cover key-limit enforcement and legal update behavior.

These repairs passed the final matrix. They do not establish complete QUIC
recovery conformance, cross-platform TLS completion or production capacity.
